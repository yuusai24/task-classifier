## 3. 編集要素ごとのまとめ

### カット割り
- カットは**3つだけ**、平均約4.3秒。**ゆっくりめのテンポ**です。
- **ジャンプカット（同じ画面で、間をつめるために切ること）はありません。**
- かわりに、**1つのカットの中でカメラを動かして**（寄る→横へ動く→引く）、見せる場所を変えています。カットが少なくても退屈しないのはこのためです。

### テロップ（画面の文字）
- 出る回数：**4回入れかわる**（0秒・3.00秒・7.84秒・9.84秒）。**約2〜5秒ごと**。
- 出し方：**パッと切りかわるだけ**。フェード（じわっと出る）や、文字が動くアニメーションは見られませんでした。
- 位置：**画面の上半分（背景の木の部分）**にメインの文字、**下（台の下）**にサブの文字。石のじゃまをしない場所に置いています。
- デザイン（場所ごとに色を変えている）：

| テロップ | 色 | フチ・光 | 書体の印象 |
|---|---|---|---|
| 霊力診断 | 緑のグラデーション | 白いフチ＋かげ。うしろに**半透明の白い帯** | 太いゴシック体 |
| あなたは霊力ある？ | ピンク | 白っぽく光る | 明朝体（筆で書いたような、とめ・はねがある書体） |
| このうち1つに〜 | ピンク（中は白に近い） | **ピンクに光る（グロー）** | 明朝体 |
| それはどれでしょう？／答えは「かみ」〜 | 白 | **青く光る** | 明朝体。「かみ」だけ大きくして目立たせる |
| 見ると何か感じる〜／あなたの中に眠る〜 | 緑 | 白いフチ＋緑の光 | 明朝体 |

- ルール：**問いかけはピンク、答えや指示は白×青、ヒントや補足は緑**、と色で役わりを分けています。

### トランジション（場面の切りかえ効果）
- **使われていません。** 2か所のカットはどちらも**ふつうの切りかえ（カット）**です。
- 3.00秒のカットの前後のコマを見ても、フェードやスライドなどの効果はありませんでした。

### ズーム・パン（カメラの動き）
- カット1：**固定**（動かない）
- カット2：**寄り → 右へパン**（A → B → C の順に石を1つずつ見せる）。手持ちのような、ゆるやかな動き
- カット3：**アップ → 引き**（3つ全部が見えるところまで下がる）。そのあとはほぼ固定（少し手ぶれ）
- 編集ソフトでのデジタルズームか、カメラを実際に動かしたかは**判断できませんでした**（動きがなめらかで少しゆれているので、手持ち撮影の可能性が高い）。

### 効果音・BGM
- **最初の0.45秒は無音**、そこから音楽が始まり、**12.8秒で終わる**（動画の終わりとほぼ同時）。
- スペクトログラムを見ると、音の線がきれいな横線で、ポーンと鳴ってだんだん消える形なので、**ピアノやオルゴールのような楽器の音**に見えます。
- 音の大きさの変化（1秒ごとの平均）：
  - 0〜1秒：小さい（-37dB）→ 4〜6秒：大きくなる（-18dB前後）→ 6〜9秒：少し小さく → **9〜10秒：いちばん大きい（最大 -8.6dB）** → そのあと小さくなる
  - いちばん大きいところ（9〜10秒）が、**「答えは『かみ』とコメントしてください！」が出るすぐ前**にあたります。
- 右と左の音がちがう（広がりのある）ステレオの音です。
- **判断できなかったこと：**
  - **BGMの曲名**
  - **ナレーション（話し声）があるか**：Whisperが使えなかったため確かめられませんでした。スペクトログラムでは話し声らしい形は見当たらず、楽器の音だけに見えます。
  - **効果音があるか**：3.7秒（「A」が出るころ）などに音の立ち上がりがありますが、BGMの音なのか、効果音なのかは区別できませんでした。カウントダウンの「3・2・1」に合わせた音も見つかりませんでした。

### 色味
- 全体に**明るめ**（明るさの平均 約150/255）。
- 画面の上（木・空）は**青緑っぽく寒色**、下（木の台・テーブル）は**オレンジ茶色で暖色**。**寒色と暖色を上下で分けた**画面です。
- 空の部分は**白くとんでいる**（明るすぎて白くなっている）ところがあり、木もれ日のキラキラ感が出ています。
- 強いフィルターは見られませんが、全体にふんわり見えます。特別な色加工をしたかどうかは**判断できませんでした**。

### 構成
- **つかみ（0〜3秒）**：「霊力診断」「あなたは霊力ある？」の問いかけ＋**3・2・1のカウントダウン**。何が始まるのか気になって、最初の3秒を見てもらえる。
- **中（3〜7.8秒）**：「このうち1つに霊力を込めました」→ A・B・Cを1つずつアップで見せる（見ている人に**選んでもらう時間**）。
- **ヒント（7.8〜9.8秒）**：「それはどれでしょう？」「見ると何か感じるのがヒント」
- **終わり（9.8〜13秒）**：「答えは『かみ』とコメントして」＋「潜在能力も診断できます」。**コメントをお願いして終わる**。
- 最後は**最初と同じ「3つ並んだ引きの画面」**で終わるので、動画がもう一度最初にもどっても違和感がありません。

### その他
- **差しこみ素材**：カウントダウン（映画のはじまり風）、A・B・Cの金色のラベル、上の半透明の白い帯。
- ワイプ（小窓）・図・アイコン：**なし**
- 人の顔・手：**出てこない**
- 字幕（セリフの文字起こし）：**なし**（テロップは全部、説明やお願いの文）

## 4. この動画の「編集のクセ・特徴」トップ5

1. **カウントダウンで始まる**
   0〜3秒に「3・2・1」を重ねて、「何か始まる！」と思わせて指を止める。
2. **カットは少なく、カメラを動かして見せる**
   3カットだけ。そのかわり、1つのカットの中で「寄る → 横へ動く → 引く」。
3. **A・B・Cの「選ばせる」しかけ**
   1つずつアップにしてラベルをつけ、見ている人に考えてもらう。何度も見返したくなる。
4. **テロップの色で役わりを分ける**
   問いかけ＝ピンク、答え・お願い＝白×青、ヒント・補足＝緑。どれも**光る（グロー）文字**で、神秘的な雰囲気。
5. **コメントのお願いで終わり、最初の画面にもどれる**
   「『かみ』とコメントしてください！」で終わる。最後の画面が最初とほぼ同じなので、くり返し再生されやすい。

## 5. 同じ雰囲気の動画を作るための再現手順（初心者向け）

スマホアプリ（CapCutなど、動画を切ったり文字を入れたりできる無料アプリ）で作れます。

### ① 撮影（約5分）
1. 見せたいもの（石・お花・カードなど）を**3つ横に並べる**。
2. うしろに**木や窓の光**が入る場所で、**縦向き**で撮る。下は木の台など暖かい色にすると、同じ色の雰囲気になる。
3. 次の3本を撮る：
   - **A：3つ全部が入る引きの映像**（スマホを動かさずに5秒）
   - **B：左のものに近づいて → ゆっくり右へ動かし、真ん中 → 右のものを順番に映す**（5〜6秒。1つにつき1秒くらい止まる）
   - **C：右のもののアップから、ゆっくり下がって3つ全部が入るところまで**（そのまま5秒ほど止める）

### ② 編集（アプリで）
1. **A（3秒）→ B（約5秒）→ C（約5秒）**の順にならべる。全体で**13秒前後**。トランジション（切りかえ効果）は**入れない**。
2. **0〜3秒**：上に「**○○診断**」（太い文字・緑・白いフチ・うしろに半透明の白い帯）、その下に「**あなたは○○ある？**」（ピンクで光る文字）。
3. 0.5〜3秒に、**カウントダウン素材（3・2・1）**を重ねる（アプリの素材やステッカーで「countdown」とさがす）。
4. **3秒〜**：「**このうち1つに私が○○を込めました**」（ピンクで光る文字・画面の上のほう）。
5. それぞれがアップになったときに、**台の上に小さく「A」「B」「C」**（金色）を出す。
6. **約8秒〜**：上に「**それはどれでしょう？**」（白＋青い光）、下に「**○○を感じるのがヒント**」（緑）。
7. **約10秒〜**：上に「**答えは『○○』とコメントしてください！**」（「○○」だけ大きく）、下に「**あなたの○○も診断できます**」（緑・小さめ）。
8. 文字は**明朝体**（とめ・はねがある書体）にして、**光る効果（グロー）**をつけると、同じ神秘的な雰囲気になる。
9. **やさしいピアノやオルゴールのBGM**を入れ、最初の0.5秒は無音にする。音楽の盛り上がりが、**10秒ごろ（コメントのお願いの直前）**にくるように位置を合わせる。
